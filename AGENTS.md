# Repository instructions

For work on the SEO and AI-discoverability programme:

1. Read docs/seo/SEO_MASTER_PLAN.md before making changes.
2. Verify completed checkpoints against the current files and live site.
3. Complete no more than one unfinished milestone, or one Milestone 8 article batch, per run.
4. Keep production changes on the seo/organic-ai-discoverability branch until the owner approves a merge.
5. Update the SEO plan, issue register and validation log with evidence.
6. Run the relevant static, link, schema and visual checks before committing.
7. Do not invent business facts, performance data, credentials, testimonials, image provenance or search-volume data.

This is a static GitHub Pages site. Preserve canonical routes and the existing noindex treatment of preview/test routes unless the current milestone explicitly changes them.
